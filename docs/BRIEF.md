# 택스컷(TAXCUT) 랜딩페이지 — 제작 브리프 (v1)

## 0. 한 줄 요약
"첫 달 기장료 0원" 광고(당근·인스타그램, 20~30대 창업 초보 사장님)로 유입된 방문자가
**30분 안에 카카오톡 상담 또는 전화상담 예약**을 하도록 만드는 단일 HTML 랜딩페이지.

## 1. 브랜드 (사용자가 첨부한 유튜브 채널 스크린샷 기준)
- 브랜드명: **택스컷** (영문 TAXCUT). 운영사: **세무회계 민** (링크 taxmin.kr, 유튜브 @taxcut_min)
- 태그라인: **"세금을 자르는 가장 빠른 방법"**
- 로고: 진한 네이비 원형 배지 안에 흰색 초굵은 "TAX / CUT" 2줄, 그 사이를 **민트그린 직선이 좌하→우상으로 가로지르며 '자르는' 취소선**.
  워드마크는 흰색 초굵은 "택스컷" 글자 위를 같은 그린 선이 관통. 위에 작은 자간 넓은 "TAXCUT" 그린 캡션.
- 컬러: 네이비 `#0B1526` ~ `#16243A` (배경, 은은한 사선 스트라이프 텍스처), 화이트 `#FFFFFF`, **택스컷 그린 `#3DDC84`** (포인트/취소선), 보조 딥그린 `#1FB86A`, 보조 뉴트럴은 네이비 기운 도는 회색.
- 로고 SVG 파일: `assets/logo-badge.svg`, `assets/logo-wordmark.svg` (페이지엔 인라인 SVG로 포함. 외부 이미지 로드 불가 환경 대비)
- **취소선(strike) = "자른다"** 모티프를 페이지의 시각적 주제로 사용: 55,000원 → 그린 선이 자르며 → 0원.

## 2. 타겟 & 톤
- 20~30대 첫 창업 사장님(스마트스토어/카페/온라인 셀러/프리랜서/배달/1인 사업자). 세무 지식 거의 없음.
- 유입 채널: 당근, 인스타그램 광고 → **거의 100% 모바일 인앱 브라우저**(Instagram in-app WebView, 당근 WebView). 모바일 퍼스트 필수.
- 톤: 친근하고 빠르고 솔직. 존댓말. 과장·거짓 긴박감 금지(30분 조건은 실제 조건). "사장님" 호칭.
- 반드시 넣을 문구(정확히):
  - `1개월 기장료 55,000원 (부가세 포함)`
  - `매출액에 따라 달라질 수 있습니다`
  - `이 페이지에서 30분 안에 상담 및 계약 완료 시 첫 달 기장료 무료`

## 3. 페이지 구성 (위→아래)
1. **상단 고정 타이머 바**: "첫 달 기장료 무료까지 남은 시간 29:59" + 30분이 줄어드는 프로그레스 바. 페이지 첫 진입 시각을 localStorage(try/catch)에 저장해 새로고침해도 이어짐. 0이 되면 바가 비고 문구가 "이벤트 시간이 종료되었어요. 그래도 상담은 가능해요"로 바뀜(CTA 유지). 남은 5분 미만이면 색/펄스로 긴박감.
2. **히어로**: 로고 + 헤드라인(취소선 모티프로 55,000원을 잘라 0원) + 서브카피 + **스크래치 복권 카드**(캔버스, 터치/마우스 지원, 3D 틸트). 긁으면 "첫 달 기장료 0원 쿠폰" + 쿠폰코드(예: `TC-` + 4자리, 세션에 1회 생성·저장) 노출 + 컨페티/스파클 + 즉시 CTA 2개 등장.
   - 긁기 전엔 CTA를 숨기지 말 것: 긁기 전에도 작은 "바로 상담" 링크는 존재(이탈 방지). 긁은 후 CTA가 크게 강조.
   - "쿠폰코드를 상담 때 말씀해 주세요" 안내.
3. **가격 섹션**: `1개월 기장료 55,000원 (부가세 포함)`, 큰 숫자, 첫 달은 0원(취소선 애니메이션). 각주: `※ 매출액에 따라 달라질 수 있습니다.` 명확히.
4. **왜 택스컷** (3~4개 포인트, 사실 범위 안에서): 카톡으로 편한 소통 / 세무사 직접 상담 / 창업 초기 사장님 맞춤 / 유튜브 택스컷 채널로 세금 정보 제공. 지어낸 수치(고객 수, 절세액 등)는 넣지 말 것.
5. **진행 절차** 3단계(실제 순서라 번호 사용 OK): ① 카톡/전화 상담 → ② 계약(온라인) → ③ 기장 시작 & 첫 달 0원.
6. **FAQ** 4~5개 (기장이 뭔가요? / 매출이 아직 없어도 되나요? / 30분 조건은 어떻게 확인하나요? / 첫 달 이후 비용은? / 계약 기간은?) — 확실치 않은 정책은 "상담 시 안내" 톤으로.
7. **최종 CTA 섹션**: 두 갈래.
   - A) **카카오톡 채널 상담**: `https://pf.kakao.com/_Mxojqs/chat` (새 탭, `rel="noopener"`). 카카오 옐로 `#FEE500` 버튼, 검정 텍스트.
   - B) **전화 상담 예약 폼**: 필드 = 이름(또는 상호), 연락처(휴대폰, 숫자 입력 `inputmode="tel"`, 010 형식 검증), 매출액(select: 아직 매출 없음 / 연 3천만원 미만 / 3천만~8천만 / 8천만~2억 / 2억~5억 / 5억 이상), 업종(select: 온라인쇼핑몰·스마트스토어 / 카페·음식점 / 프리랜서·콘텐츠 / 배달·서비스 / 도소매 / 제조 / 기타 + 기타 직접입력), 사업자등록일(date + "아직 등록 전" 체크), 상담 가능 시간(select: 평일 오전 9~12시 / 오후 12~3시 / 오후 3~6시 / 저녁 6시 이후 / 주말·공휴일 + 메모), 개인정보 수집·이용 동의(필수 체크, 수집 항목/목적/보유기간 짧게 명시), 숨김 필드: 쿠폰코드, 이벤트 남은 시간(초), 유입 경로(URL의 utm_source), 제출 시각.
   - 제출 후: 성공 화면 "예약 완료! 영업시간 내 순서대로 전화드릴게요" + 카톡 상담 버튼도 함께.
8. **푸터**: 세무회계 민 · 택스컷 / taxmin.kr / 유튜브 @taxcut_min / "개인정보처리방침"(앵커) / 이벤트 유의사항(30분 조건, 매출액에 따른 요금 변동).
9. **하단 고정 CTA 바(모바일)**: 스크롤 시 항상 보이는 "카톡 상담" + "예약하기" 2버튼. `padding-bottom: env(safe-area-inset-bottom)`.

## 4. 예약 데이터 저장(DB) 설계 — "구현 가능한지"에 대한 답
- 저장소 미정이므로 **어댑터 방식**: 파일 상단 `const TAXCUT_CONFIG = { RESERVATION_ENDPOINT: "", RESERVATION_MODE: "auto", KAKAO_URL: "https://pf.kakao.com/_Mxojqs/chat", EVENT_MINUTES: 30, ... }`
- `RESERVATION_MODE`: `"webhook"` → `RESERVATION_ENDPOINT`로 JSON POST (Google Apps Script 웹앱이면 `mode:"no-cors"` + `Content-Type: text/plain` 로 보내야 CORS 프리플라이트가 안 걸림 / 일반 API면 `application/json`). `"local"` → localStorage 배열에 저장(테스트 모드, 화면에 "테스트 모드: 이 기기에만 저장됨" 배지). `"auto"` → ENDPOINT가 비어있으면 local, 있으면 webhook.
- 실패 시 사용자에게 "예약이 잘 안 됐어요. 카톡으로 바로 상담해 주세요" + 카톡 버튼 (데이터 유실 방지 폴백).
- 별도 파일 `docs/apps-script.gs`: 구글 시트에 한 줄 추가 + 사무실 이메일 알림(MailApp) 샘플. (이 파일은 메인 에이전트가 작성)

## 5. 기술 규약 (아티팩트 CSP + 배포 겸용)
- **단일 HTML 파일**. 외부 스크립트는 `https://cdnjs.cloudflare.com` 또는 `https://cdn.jsdelivr.net/npm/` 에서만, 버전 고정. 외부 CSS는 Google Fonts만(`fonts.googleapis.com`). 이미지/폰트파일/fetch는 외부 호스트 불가 → SVG 인라인, 이미지 data URI. (예외: 예약 웹훅 fetch는 실제 배포 시에만 동작, 아티팩트 프리뷰에선 local 모드로 자동 폴백되도록 try/catch)
- 폰트: Google Fonts. 한글 디스플레이는 `Black Han Sans`(초굵은 헤드라인) 또는 `Do Hyeon`/`Gothic A1 900`, 본문은 `Noto Sans KR` 또는 `Pretendard` 대체로 `Noto Sans KR`. 숫자/타이머엔 `Montserrat`/`Bebas Neue`/`Anton` 같은 임팩트 있는 라틴 폰트 + `font-variant-numeric: tabular-nums`. 반드시 폴백 스택.
- **3D**: 다음 중 성능이 보장되는 조합만. (a) CSS 3D: 스크래치 카드 perspective 틸트(포인터/터치 이동 + `deviceorientation` 있으면 사용), 층이 있는 카드/코인. (b) Three.js `https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js` 로 가벼운 배경 씬(떠다니는 코인/지폐 조각 파티클 수십 개 이하, `devicePixelRatio` 최대 1.5, 탭이 숨겨지면 정지, WebGL 실패 시 CSS 폴백, `prefers-reduced-motion`이면 정지). 중저가 안드로이드 인앱 브라우저에서 60fps 근접해야 함. 무거운 후처리·그림자 금지.
- 모바일 퍼스트(400px)에서 완벽, 데스크톱(1200px)에서도 보기 좋게. 좌우 여백 16px 이상, 가로 스크롤 금지.
- 테마: 브랜드 다크 네이비 단일 테마로 확정(딥 다크 고정 디자인). 단, 모든 색은 `:root` 토큰으로 정의하고 `body` 배경을 명시. 밝은 섹션(가격/폼)을 넣어 리듬을 줘도 좋음.
- 접근성: 포커스 링, 버튼은 `<button>`/`<a>`, 폼 컨트롤은 `id`+`label`, 타이머는 `aria-live="polite"`(매초 갱신은 aria-live 밖에서, 분 단위로만 알림), 색 대비 4.5:1.
- `prefers-reduced-motion` 존중(애니메이션 최소화). 페이지 로드 직후 모든 텍스트가 보이는 상태(opacity:0 대기 금지).
- 페이지 `<title>`은 `택스컷 첫달 0원` 처럼 2~4단어 이름. 파일 최상단에 `<title>`과 `<style>`.
- 스크립트: 프레임워크 없이 바닐라 JS. 전역 오염 최소화(IIFE). 모든 localStorage 접근 try/catch. 폼 검증은 JS + HTML5.
- 이모지를 섹션 마커로 남발하지 말 것. 카톡 버튼엔 인라인 SVG 말풍선 아이콘.
- **완전한 standalone 문서로 작성**: `<!doctype html><html lang="ko"><head>…<meta charset><meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">…`. 이후 메인 에이전트가 아티팩트용 본문을 추출함.

## 6. 산출물
- 후보 파일 경로: 각 빌더는 지정된 절대경로에 1개 HTML 파일만 작성.
- 파일 상단 주석에: 사용한 폰트, 3D 방식, 설정 방법(`TAXCUT_CONFIG`) 5줄 이내.
